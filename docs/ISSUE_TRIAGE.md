## Scope and method

The GitHub open-issues inventory contained 91 open records: 86 issues and five pull requests. The pull requests were excluded from this issue triage: [#329](https://github.com/RuleWorld/bionetgen/pull/329), [#330](https://github.com/RuleWorld/bionetgen/pull/330), [#331](https://github.com/RuleWorld/bionetgen/pull/331), [#332](https://github.com/RuleWorld/bionetgen/pull/332), and [#333](https://github.com/RuleWorld/bionetgen/pull/333).

I read every open issue body, reviewed available comments, compared claims with the exact upstream source snapshot above, and used small isolated reproductions where the repository provided enough information. The original shared checkout was refreshed with `git pull --ff-only --autostash` before the audit; this issue branch was then created cleanly from the upstream target so local-only changes were not treated as upstream fixes.

Triage priorities are relative queue recommendations, not GitHub labels:

- **P1**: correctness, memory safety, hard failure, or interoperability issue that can invalidate results or block users.
- **P2**: important performance, portability, backend, compatibility, or high-value feature work.
- **P3**: maintenance, documentation, polish, or low-risk enhancement.

Disposition terms:

- **Confirmed defect**: current source or a current reproduction supports the report.
- **Partial/fixed**: some or all of the reported behavior is addressed, but a residual issue or compatibility decision remains.
- **Fixed/stale**: the reported defect is not present in the inspected target; close after recording the evidence.
- **Needs reproduction**: plausible or externally dependent, but no current pinned model/oracle was available.
- **Enhancement/design**: a valid request that needs an explicit semantic, API, or UX decision rather than an unreviewed bug fix.
